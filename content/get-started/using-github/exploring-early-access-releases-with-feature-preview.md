## {% data variables.product.prodname_dotcom %}'s release cycle

{% data variables.product.prodname_dotcom %}'s products and features can go through multiple release phases.

| Phase | Description |
| --- | --- |
| {% data variables.release-phases.private_preview_caps %} | The product or feature is under heavy development and may change. It is available for demonstration and testing, and might not be documented. {% data variables.release-phases.private_preview_caps %} releases are not necessarily feature complete, have no service level agreements (SLAs), and do not include technical support. <br><br> **Note:** A product or feature released as a "Technology Preview" is considered to be in the {% data variables.release-phases.private_preview %} stage and shares the same characteristics described above. |
| {% data variables.release-phases.public_preview_caps %} | The product or feature is ready for broader distribution. {% data variables.release-phases.public_preview_caps %} releases can be public or private, are documented, but do not include SLAs or technical support. |
| General availability (GA) | The product or feature is fully tested and available to all users. GA releases are ready for production use, and associated SLAs and technical support obligations apply. |

## Explore {% data variables.release-phases.public_preview %} releases with feature preview

You can view a list of features that are available in {% data variables.release-phases.public_preview %}, with a brief description for each. Each feature includes a link to provide feedback.

{% data reusables.feature-preview.feature-preview-setting %}

1. In the left sidebar, click a feature’s name to view details.
2. To turn a feature on or off, click **Enable** or **Disable** to the right of the feature’s name.
